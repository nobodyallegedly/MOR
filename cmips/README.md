# Founding cMIPs

Community specifications for the tasks the MIPs hand out, and for what no task foresaw. Not core: each is named by its hash, frozen at publication, and competes with any other cMIP for the same job.

Planned for MOR 0.1:

| cMIP | What it does |
| --- | --- |
| Relay transport (`cmip-relay-transport-draft-1.md`, draft 1, awaiting Nobody, allegedly) | How a client publishes, fetches and follows acts, delivers to an inbox, and asks a home for a receipt. The core deliberately leaves this open. |
| Long-form text format | Task 4 (text format): formatted text on top of canonical text, hiding only markup, never letters or digits. |

Media types such as JPEG are Modules and live in `modules/`.
