# The round's real acts, a sample

Fifty public Agreements acts of round two (draft 25, encoding 2): 20 Terms and 30 Statements, each
copied byte for byte from the round's `_research/windows/<keptBy>/acts/<id>.mor`, with
`sample-manifest.json`, which drew them (its rule: seed 20261125, `random.Random(seed).sample` from the
Agreements acts some window kept, each list sorted by id first) and lists each act's id, type, signer,
body cMIP and the window that kept it.

A sample, not the round's data: no other act, no window's notes or reports. For the draft-25 tests
only (`test/agreements-25.test.ts` here, and Edubba's `clients/desk/test/agreements-25.test.ts`), read by
`test/real-acts.ts`. Copied by DubLaw, wave 3, session D2, 26 November 2026.
