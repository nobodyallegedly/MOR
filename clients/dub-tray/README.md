# Dub for trays

Round two's Dub, from the Dubsar Suite: a client for players' windows, which have no network. It writes letters to the tray's `out/` and reads `in/`, like the hosts' kit, and uses the kit's core library and signing. Published on MOR as media (SHA-256 `ec035b45f5fd45ae304a10fa3c85f2b70b1a083af306e429e8368a16e49dc571`, version 0.1.0); this file is the same bytes.

It shows authors only by names the reader gives them (`dub/names.json`), never by names they claim, and marks new identities, replies to the reader, invoices and claims of being someone else. Proof of concept: not yet tested in CI.
