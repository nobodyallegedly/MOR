# MOR companion documents

Companion documents are written for readers outside the project. They explain MOR; they are not part of the core and add no rule. The core document and the six MIPs in `spec/` define the protocol.

- [Who Can Earn on MOR](05-MOR-who-can-earn-v6.md): the roles MOR opens, what each one does and how it gets paid.
- [Core principle: Don't ban greed, make it legible](Core-principle-legible-greed-v3.md): why the core never judges whether a deal is fair, and what it guarantees instead.

"MOR in one page" is at [`docs/07-MOR-in-one-page-v5.md`](../07-MOR-in-one-page-v5.md). The case studies are in [`../case-studies/`](../case-studies/README.md).

*These are working drafts. The documents that are neither core nor technical companions get a final draft by Nobody, allegedly, before publication.*
