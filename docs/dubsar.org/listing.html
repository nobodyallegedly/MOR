Extensions, cMIPs and Modules

One listing among any; anyone can run another. It decides nothing and refuses nothing.

An extension is a cMIP an agreement names for work the core did not foresee. Each one marks a place MOR 2 may answer, so this page shows first which cMIPs agreements name as extensions, and how often. It reads public agreements only: private ones are not counted.

Anyone can write a cMIP or a Module and publish it, signed as their own; it is named by the hash of its content, not by being listed anywhere. This page reads what is published on the relays below and checks each one in your browser: who signed it, and that it is what they signed. What each one is, the task it fills, the layer, its drafts, and whether code is released for it, comes from its own fields.
