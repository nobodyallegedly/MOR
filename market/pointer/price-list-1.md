# Pointer: price list 1

*6 November 2026. Published by Pointer, to be signed as an act by Pointer's identity (a test identity until MOR is frozen). Nothing is updated: a change is a new price list, signed again, and this one stays readable.*

## Terms of this list

1. **The same for every customer.** No discounts, no private rates.
2. **Every fee is a line in signed terms.** No Pointer fee is built into any cMIP or Module we publish.
3. **A lower price applies at once to everyone, a higher one only to new services 60 days after it is signed.** A service already contracted keeps the fee its signed terms carry, unless this list is lower.
4. **Nothing is sold for real use before the freeze.** Until then, every service runs on a test network with test identities.

Prices in Swiss francs.

| Service | Price |
| --- | --- |
| Reader client, for subscribers and buyers | Free. Pointer earns only the client role share, on payments where the buyer chose Pointer |
| Desk setup, shared rulebooks: a set of published rulebooks used by several customers, identical by hash | 1,800 once per set, divided equally among the customers who use it, each new customer's part refunded to the earlier ones in equal parts |
| Desk setup, a customer's own: its own deals, bundle, templates, rehearsal before launch | 1,200 one-off |
| Desk, per publishing member | 8 per month, each member's choice |
| Member onboarding: one hour, first release done together | 120 per member, each member's choice |
| Release-night support | Included for members on the desk |
| Client role share | 1% of each payment, proposed in every customer's split plan; filled payment by payment by the one client record that payment's claim acknowledges; never taken on real money before the core's vectors for it exist and the freeze |
| Our published cMIPs and Modules | Free, open, replaceable |

*A customer using only shared rulebooks and nothing of its own pays its part of the shared set. A set changed by one customer is that customer's own from then on.*

*Everything above can be done with Dubsar's tools alone, at no fee. What a customer pays Pointer for is the desk working on the night of a release, the checks it runs on every member's behalf, and someone answering when it fails.*
